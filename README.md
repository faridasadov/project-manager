# Project Manager

Static project management workspace with login roles, tasks, resources, comments, attachments, backup/import, deadline alerts and GitHub Pages deployment.

## Demo users

- `admin / admin123`
- `manager / manager123`
- `user / user123`

## Local test

```bash
node test-runner.mjs
```

## GitHub Pages

The `.github/workflows/pages.yml` workflow deploys the static site from the `main` branch. In the GitHub repository, enable Pages with **GitHub Actions** as the source.
